# Acme Agent

[English](product.md) | Español

Acme Agent es un agent harness de código abierto que automatiza las tareas rutinarias del repositorio.

Este párrafo contiene texto de relleno neutral para el ejemplo.

## Instalación

Instala Node.js 24 y luego ejecuta:

```sh
npx acme-agent setup
```

El comando imprime la URL de configuración, que de forma predeterminada es `http://127.0.0.1:3080`.

## Comunidad

- Informa de errores en el rastreador de issues.
- Añade el tema `acme-agent` a tu repositorio de plugins.
